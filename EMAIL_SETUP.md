## Troubleshooting

### Error: "SMTP Authentication failed"
**Cause**: Wrong email or app password
**Solution**:
- Verify email is: nabiikhalils091@gmail.com
- Verify app password is: wkci wqnl vbka nhey (with spaces)
- Check `.env` file has correct values

### Error: "Connection refused"
**Cause**: Gmail SMTP server unreachable
**Solution**:
- Check internet connection
- Verify SMTP_HOST is: smtp.gmail.com
- Verify SMTP_PORT is: 587

### Error: "Code not received"
**Cause**: Email went to spam/junk folder
**Solution**:
- Check spam folder
- Wait 10 seconds for email to arrive
- Check email entered correctly in signup form
- Look at backend logs for errors

### Error: "2-Step Verification required"
**Cause**: Gmail account security setting
**Solution**:
1. Enable 2-Step Verification on Gmail account
2. Generate new App Password at https://myaccount.google.com/apppasswords
3. Update SMTP_PASS in .env file

## FAQ

**Q: Can I use regular Gmail password instead of App Password?**
A: No. Gmail blocks SMTP connections with regular passwords for security. You must use an App Password (16 characters).

**Q: Why is my code expiring in 10 minutes?**
A: This is intentional for security. Users have 10 minutes to verify their code, which is plenty of time to check their email.

**Q: Can I change the code format (e.g., alphanumeric)?**
A: Yes, edit `/backend/config.py` → `CODE_LENGTH = 6` and modify `generate_verification_code()` in `auth_utils.py`.

**Q: Why am I not receiving emails?**
A: Check:
1. Email address spelled correctly in signup form
2. Correct Gmail app password in .env file
3. Backend is running and logs show "Email sent successfully"
4. Check spam/junk folder
5. Verify 2-Step Verification is enabled on Gmail account

**Q: How do I change the email sender address?**
A: Update `SMTP_USER` in `.env` file to a different Gmail address (you'll need to generate a new app password for that account).
