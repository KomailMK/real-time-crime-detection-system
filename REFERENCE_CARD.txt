TROUBLESHOOTING:
┌────────────────────────────────────────────────────────────────────────────┐
│ "pip not found"           → python -m pip install -r requirements.txt    │
│ "python not found"        → Use python3 or py instead                      │
│ "MySQL connection error"  → Check .env file & MySQL password              │
│ "Port 5000 in use"        → Kill process: netstat -ano | findstr :5000  │
│ "Still missing module"    → pip install --force-reinstall -r req*.txt    │
└────────────────────────────────────────────────────────────────────────────┘
